# Experiment

Experiment folders follow the requested naming convention.

## Experiment Folders

- `[experiment 1]ImageReward main difficulty split`: main Hard/Mid/Easy decomposition and Table 1 pipeline.
- `[experiment 2]interface perturbation robustness`: prompt rephrasing and image-order perturbation pipeline.
- `[experiment 3]Pick-a-Pic generalization`: Pick-a-Pic sampled validation and Table 4 pipeline.
- `[experiment 4]temperature ablation`: Auction temperature ablation on ImageReward.
- `[experiment 5]hardness protocol ablation`: pair-gap, human-only, model-only, and dual-filter protocol comparison.

## Phenomenon Folders

- `[phenomenon 1]hard-instance gap`: supporting plots and table source for the hard-instance gap.
- `[phenomenon 2]zero-gap signal collapse`: Zero-gap and feature-signal collapse analysis.
- `[phenomenon 3]protocol separation`: hardness protocol separation figure source.

Large raw images and transient runtime files are intentionally not included.
