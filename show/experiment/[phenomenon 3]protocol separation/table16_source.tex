For the three group-level protocols, we assign Hard/Mid/Easy at the group level and then audit \emph{all valid pairs} inside the selected groups using the same pair-level metrics. This lets us test whether each protocol induces a meaningful behavioral difficulty gradient rather than relying on group-level top-rank recovery alone. The \textbf{Overall} column always reuses the full pair set, so it is numerically identical across the four protocols. Best PairAcc and best AUROC in each column are shown in \textbf{bold}. \textit{Caution:} the Llama3.2V-11B Single-agent (Pair) row is flagged by an order-template contamination diagnostic (monotonic saved ranks, low top-1, repeated position-like rankings), so its unusually high pairwise scores should be interpreted as potentially inflated rather than clean model gains.}
