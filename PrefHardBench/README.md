# 图像偏好标注数据集  imagepref_anno_v1_20260922

人类对「同一段提示词下两张图」的偏好标注。**一个表 + 一个图片目录**，自包含、可离线使用。

```
data_annotations.csv   唯一的标注表：一行 = 一条判断
images/                图片（WebP），文件名与表里的 image_left / image_right / chosen / rejected 对应
```

## 整理口径

- **已保留**：用时超过 30 分钟的整份、以及从未点提交的整份 —— 都视为合格样本；
- **已剔除**：① 无题号/无图片的历史记录；② 判断、自信、归因三题没有答全的记录；
- **未包含**：问卷用时、是否计入有效票、开始时间、提交时间。

## 字段

| 字段 | 含义 |
|---|---|
| session_id | 一份问卷的会话号；同一次填写的各行相同，可用于分组 |
| question_id | 题组单元号 U00001–U05000（一段提示词 + 两张图） |
| slot | 该判断在该份问卷中的位置，1–12 |
| prompt_en / prompt_zh | 提示词英文原句 / 中文翻译 |
| image_left / image_right | 左图、右图的文件名（文件在 `images/` 下） |
| judge | 判断结果：`A` 左图更好，`B` 右图更好，`U` 不确定 |
| chosen / rejected | 所选侧 / 另一侧的文件名；`U` 时为空（没有胜者） |
| confidence | 自信程度 1–5，题面「你有多确定自己刚才的选择是对的？」 |
| reason | 归因码（见下表）；选 A/B 为单选，选 U 可多选，多选用 `|` 连接 |
| reason_other | 归因选「其他」时的自由填写（本批全为空） |

空的含义：单元格留空表示「无此值」。`chosen`/`rejected` 为空 = 该题判为「不确定」，不存在胜负；`reason_other` 为空 = 选填项未填写。

## 图片

全部图片放在 `images/` 目录下，表里的 `image_left`、`image_right`、`chosen`、`rejected` 四列存的都是**文件名**，与 `images/` 中的文件一一对应；路径为 `images/<文件名>`。

## 归因码表

| 码 | 标签 | 判定口径 |
|---|---|---|
| `a1` | 两图几乎无可见差异 | 对齐、画质、整体观感都相当，放大或逐项对比也难以找到稳定差异 |
| `a2` | 有可见差异，但难分高下 | 风格/侧重/观感不同，或两图都好/都差，不存在客观的优劣方向 |
| `a3` | 两图各在不同方面更好，难以权衡 | 例如 A 更贴提示词、B 画质更好，给不出统一权重 |
| `a4` | 提示词不清楚或有歧义 | 两种结果都可算合理地满足提示词；困难源于 prompt，而非这对图 |
| `a5` | 主要是个人审美/口味差异 | 换一位标注者很可能选另一边 |
| `a6` | 两侧各有相当的错误或缺陷 | 伪影、文字错乱、数量/空间错误等各占一边，整体都不理想、难定胜负 |
| `a7` | 说不清具体原因，就是定不下来 | 兜底项，避免强制归因 |
| `other` | 其他（请填写） | 自由填写 |
| `b1` | 文图对齐差距显著，主导了我的选择 | 所选侧明显更贴合提示词（内容/布局/属性/文字等） |
| `b2` | 视觉质量差距显著，主导了我的选择 | 清晰度、真实感、细节、无伪影、色彩等画质明显更强 |
| `b3` | 构图 / 审美 / 风格差距显著，主导了我的选择 | 整体观感、构图、光影或风格明显更优 |
| `b4` | 跨维度权衡后一方胜出 | 两图各有所长（如对齐 vs 画质），但某一维优势大到足以定下方向 |
| `b5` | 明显错误集中在另一侧 | 文字错乱、数量或空间关系错误、局部伪影/畸变等使对侧直接出局 |
| `b6` | 两图总体接近，只是整体观感略偏所选侧 | 弱偏好、把握不大——接近但勉强选了这边 |
| `b7` | 说不清具体维度，凭整体第一印象 | 直觉型判断，未逐项比较 |
| `other` | 其他（请填写） | 自由填写 |
